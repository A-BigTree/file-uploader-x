# 通用上传器

把工作目录里的文件上传到 Cloudflare R2 对象存储，并返回可公开访问的链接。

## 能做什么

- 将本地工作目录中的单个文件上传到 Cloudflare R2 存储桶
- 默认对大于 64MB 的文件自动启用串行分片上传，无需手动干预
- 上传成功后输出一个可公开访问的 URL，供下游输出插件直接使用
- 支持按原文件名、唯一名、内容哈希、日期目录 + 唯一名四种方式命名对象

## 什么时候用它

| 场景 | 怎么设 |
|---|---|
| 图片 / 视频等内容投递到 R2 后用 CDN 分发 | 配置好 R2 凭证与「公开访问域名」即可 |
| 大文件（影视素材、安装包等）需要稳定上传 | 保持「启用分片上传」为开，分片大小用默认 64MB |
| 想避免覆盖存储桶里已有的同名对象 | 关闭「允许覆盖同名对象」 |
| 希望对象名可预测、按日期归档 | 「对象命名方式」选「日期目录 + 唯一名称」 |

## 配置方法

### 第一步：让文件先进入工作目录

本插件只上传**工作目录**中的文件。请先在流水线中配置并运行「默认输入处理器」，
它会把外部文件（本地路径或网络地址）引入工作目录并嗅探文件类型。否则本插件会因取不到文件而失败。

### 第二步：填写 R2 凭证

在「Cloudflare R2」分组里填入 Cloudflare 账户 ID、存储桶名、Access Key ID 与 Secret Access Key。
这些值在 Cloudflare 控制台的 R2 设置中创建 API Token 时获得。

### 第三步：填写公开访问域名

「公开访问域名」是上传成功后返回链接的前缀，必须以 `http://` 或 `https://` 开头，
填 R2 存储桶绑定的自定义域名或 `r2.dev` 开发域名（例如 `https://cdn.example.com`）。
该域名必须已在 Cloudflare 侧为该存储桶开启。

## 参数一览

### 通用参数

| 参数 | 作用 | 默认 | 怎么填 |
|---|---|---|---|
| 请求超时（秒） | 单次 HTTP 请求的超时秒数 | 30 | 网络较差时适当调大 |
| 失败重试次数 | 单次上传或每个分片独立重试的次数 | 2 | 0 表示不重试 |
| 对象命名方式 | 上传后对象的命名策略 | 日期目录 + 唯一名称 | 见下表 |
| 对象键前缀 | 对象名的公共前缀 | 空 | 例如 `uploads/`，不得以 `/` 开头或含 `..` |
| 启用分片上传 | 大文件是否走分片 | 开 | 关闭后一律单次上传 |
| 分片大小 | 单个分片的体积阈值 | 64MB | 范围 5MB 至 5GB |

**对象命名方式**

| 选项 | 效果 |
|---|---|
| 原文件名 | 保留上传文件名（清洗掉路径与危险字符） |
| 唯一名称 | 生成 `时间戳_随机串.扩展名`，不会重名 |
| 内容哈希 | 用文件内容的 SHA-256 前 16 位命名 |
| 日期目录 + 唯一名称 | 在前缀后按 `年/月/日/` 归档，再加唯一名 |

> 「唯一名称」「日期目录 + 唯一名称」中的唯一名是 `时间戳_随机hash`，**不是** RFC 4122 标准的 UUID。

### Cloudflare R2 参数

| 参数 | 作用 | 必填 |
|---|---|---|
| Account ID | Cloudflare 账户 ID | 是 |
| Bucket | R2 存储桶名称 | 是 |
| Access Key ID | R2 API Token 的 Access Key ID | 是 |
| Secret Access Key | R2 API Token 的密钥（保密） | 是 |
| 公开访问域名 | 上传后返回链接的前缀 | 是 |
| 允许覆盖同名对象 | 关闭时上传前会先检查对象是否存在 | 否，默认开 |

## 上传结果

上传成功后，文件数据会被改写为「网络路径」：可直接访问的 URL 成为文件的主路径。
本地路径、对象名与存储供应商会附带在扩展信息里，供下游插件（如通用输出器）取用。

## 常见问题

**问：上传报 403 / 签名错误？**
答：最常见是 Access Key ID / Secret Access Key 填错，或系统时间偏差过大。
请到 Cloudflare 控制台重新核对 Token 权限（至少需要该存储桶的对象读写权限）。

**问：大文件上传中途失败，存储桶里留下了未完成的分片？**
答：上传失败时本插件会尝试中止（Abort）这次分片上传并清理已传分片。
若中止本身也失败了，错误消息里会带上 `uploadId`，你可以用它在 R2 控制台或 API 手工清理未完成的分片上传。

**问：开启分片上传会更省内存吗？**
答：不会。分片上传是为了应对单次请求超时与大文件稳定性，不是为降低内存占用。
默认 64MB 阈值意味着：不超过 64MB 的文件走单次上传，超过的走串行分片。

**问：为什么提示取不到文件？**
答：本插件只读工作目录里的文件。请确认流水线中「默认输入处理器」已在本插件之前运行，
且它的「缓存本地文件」/「下载网络文件」开关已开启（默认均为开）。
