# 通用输出器

把已上传文件的可访问链接，格式化为 Markdown、HTML 或纯超链接文本。

## 能做什么

- 将上游产出文件的 URL 转成 Markdown 图片 / 链接、HTML `<img>` 标签或纯链接
- 图片类型（`image/*`）自动用 Markdown 图片语法，其它类型用链接语法
- 支持自定义模板，用占位符自由拼接输出内容

## 什么时候用它

| 场景 | 怎么设 |
|---|---|
| 把上传结果贴进 Markdown 文档 / 笔记 | 「输出格式」选 Markdown |
| 在网页里直接嵌入图片 | 「输出格式」选 HTML |
| 只想要一条可点击的链接 | 「输出格式」选超链接 |
| 需要拼成自定义格式（如 BBCode、JSON） | 填「自定义模板」 |

## 配置方法

本插件只消费上游产出的「网络路径」文件——也就是已带可公开访问 URL 的文件。
请先在流水线中配置上传类插件（如「通用上传器」），它会把文件上传并产出 URL，本插件再据此生成文本。

无需任何凭证，也不读写磁盘、不访问网络。

## 格式示例

假设文件名 `a.png`，URL `https://cdn.example.com/a.png`，类型 `image/png`：

| 格式 | 输出 |
|---|---|
| Markdown | `![a.png](https://cdn.example.com/a.png)` |
| HTML | `<img src="https://cdn.example.com/a.png" alt="a.png">` |
| 超链接 | `https://cdn.example.com/a.png` |

非图片类型（如 PDF）用 Markdown 时会输出链接语法：`[a.pdf](https://cdn.example.com/a.pdf)`。

## 模板占位符

「自定义模板」非空时，会忽略上面的格式设置，按模板原样替换占位符输出：

| 占位符 | 替换为 |
|---|---|
| `{url}` | 文件的访问 URL |
| `{name}` | 文件名 |
| `{size}` | 文件大小（字节数） |
| `{type}` | 文件类型（MIME） |

示例：模板 `{name}|{url}|{size}|{type}` 输出 `a.png|https://cdn.example.com/a.png|12|image/png`。

## 常见问题

**问：提示「仅接受网络路径文件」？**
答：本插件只处理已上传、带 URL 的文件。请确认上游的上传插件已成功执行，并把文件改写为网络路径。
若上游文件仍是本地路径，本插件会直接失败。

**问：模板里的内容会自动转义吗？**
答：不会。自定义模板按字面替换占位符，不做任何转义或编码。
如需转义，请在模板里手动处理，或改用内置的 Markdown / HTML 格式（它们会自动转义）。

**问：HTML 格式对 URL 和文件名都转义了吗？**
答：是的。HTML 格式会对 URL 与文件名做 HTML 实体转义（`&`、`<`、`>`、`"`、`'`），
Markdown 格式会对文件名转义 `\ [ ] ( )` 并对 URL 中的空格、圆括号做百分号编码。
