# 上传文件校验器

在文件真正上传之前，把不想要的文件拦下来。

## 能做什么

- 只收图片，其他类型一律拒掉
- 拦住超过 10MB 的大文件
- 只收 `.png` 结尾的文件
- 拦住 zip、exe 这类危险文件
- 连类型都识别不出来的文件，直接不收

以上几件事可以任意组合。

## 什么时候用它

| 场景 | 怎么设 |
|---|---|
| 头像上传 | 只收图片，限制 2MB |
| 文档上传 | 只收 PDF 和纯文本 |
| 附件上传 | 拦住压缩包和视频 |
| 图床 | 只收图片，单张限 20MB，开启严格模式 |

## 怎么配

### 只收图片

「允许类型」选 `图片(image/*)`，其余参数不填。

- 上传 png、jpg、gif → 通过
- 上传 pdf、txt → 被拒

### 只收图片，但不要 gif

「允许类型」选 `图片(image/*)`，「拦截类型」自己填一项 `image/gif`。

拦截优先于允许 —— 只要命中拦截，即使在允许名单里也会被拒。

### 限制文件大小

「最大体积」填 `10mb`。

可以写 `500kb`、`10mb`、`2gb` 这样带单位的写法，也可以直接写字节数。
**填 `0` 或者留空表示不限制大小。**

### 按文件名收

「允许文件名」填 `*.png`，可以填多条，命中任意一条就算通过。

常见写法：

| 填什么 | 效果 |
|---|---|
| `*.png` | 只收 png 结尾的 |
| `*.jpg`、`*.jpeg` | 两条都填，jpg 和 jpeg 都收 |
| `report-*` | 只收以 report- 开头的 |
| `*` | 全都收（等于不填） |

### 连类型都识别不出来的，不要

打开「严格模式」。

有些文件（改过后缀的、损坏的、自定义格式的）系统识别不出真实类型，
默认情况下这类文件会放过去。打开严格模式后会直接拒掉。

### 什么都不填会怎样

全部放过。不填任何参数时这个插件相当于不做事。

## 参数一览

| 参数 | 作用 | 默认 | 怎么填 |
|---|---|---|---|
| 允许类型 | 白名单，只收这些类型 | 空（全收） | 下拉选，也可自己填；`image/*` 这种星号写法表示一整类 |
| 拦截类型 | 黑名单，命中就拒 | 空（不拦） | 同上；比允许类型优先 |
| 允许文件名 | 按文件名筛 | 空（全收） | 填 `*.png` 这类通配写法 |
| 最大体积 | 单个文件的大小上限 | 不限 | `10mb`、`500kb`、`2gb`；`0` 或留空为不限 |
| 严格模式 | 识别不出类型就拒 | 关 | 开 / 关 |

**判定顺序**：先看是否在允许类型里 → 再看是否被拦截类型命中 → 再看文件名 → 再看大小 → 最后看严格模式。
任何一步不通过，这个文件就被拒。

## 常见问题

**为什么我的图片被拒了？**

按这个顺序排查：

1. 「拦截类型」里是不是填了 `image/*` 或者具体的图片类型？拦截优先级最高。
2. 「允许文件名」是不是填了但没匹配上？比如填了 `*.png` 但你上传的是 jpg。
3. 文件是不是超过了「最大体积」？
4. 「严格模式」是不是开着，而这个文件的类型识别失败了？

被拒时的提示信息里会打印出实际生效的全部参数，对照着看即可。

**「最大体积」填了 `10 兆` 或 `ten mb`，保存时报错**

只认数字加单位的写法，单位限 `b`/`kb`/`mb`/`gb`/`tb`（大小写都行）。
写 `10mb`、`10MB`、`10 mb` 都可以，写中文或英文单词不行。

**「允许类型」里没有我要的类型**

下拉列表只是常用项，可以直接自己输入，比如 `application/vnd.ms-excel`。
也支持 `application/*` 这种一整类的写法。

**只想限制大小，不想管类型**

只填「最大体积」，其他全部留空即可。

**为什么改了后缀名还是被拦住了？**

因为判断类型看的是文件内容本身，不是后缀名。把 exe 改名成 png 也照样能被识别出来。
如果要按后缀名筛，用「允许文件名」这个参数。

**上传的文件全都被拒了**

大概率是「允许类型」和「允许文件名」互相冲突了 —— 两个都填了，但没有文件能同时满足。
先只留一个试试。
